# Kodex chování

U jednoho stolu vítáme hráče i přispěvatele s různými zkušenostmi. Tato pravidla platí pro komunikaci kolem projektu na GitHubu, zejména v issues, pull requestech a jejich komentářích.

## Jak spolu jednáme

- Mluv věcně a s respektem. Při nesouhlasu vysvětli, co ti vadí na návrhu nebo změně.
- Dej prostor začátečníkům a lidem, kteří potřebují jiný způsob komunikace nebo ovládání aplikace.
- Obtěžování, výhrůžky, osobní útoky, diskriminace a zveřejňování cizích osobních údajů bez souhlasu do diskuse nepatří.

## Jak nahlásit porušení

V nabídce u komentáře, issue nebo pull requestu zvol **Report content**. Pokud GitHub nabídne **Report to repository admins**, můžeš oznámení poslat správcům repozitáře. Jinak použij **Report abuse to GitHub Support** nebo formulář podpory. Uveď odkaz na daný příspěvek a stručně popiš, co se stalo. Citlivé podrobnosti sdílej přes soukromé hlášení. [Postup hlášení na GitHubu](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

Správci mohou podle závažnosti upozornit na porušení pravidel, skrýt nebo odstranit příspěvek, uzamknout vlákno či omezit další účast. Technické zranitelnosti mají vlastní [bezpečnostní postup](SECURITY.md).
